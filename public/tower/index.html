TEXT FIRST · LOCAL ARCHIVE IMPORT

Your history is the foundation.

Import your existing OpenAI conversations.json. Processing stays on this device. Original text and branches are preserved; importing does not approve a personality or generate an avatar.

Before you start

If your export is a ZIP, extract it in Android’s Files app and select conversations.json. Keep the original export as your backup. Use this same browser and address to return to imported data.

Large archives are processed a conversation at a time. Keep this tab open. Switching apps requests a safe pause; Android may still stop the tab. Reselect the original file to resume. Conversations larger than 32 MiB stop with an explicit limit message.

No data is uploaded to a server or sent to an AI. Attachments are referenced, not copied or interpreted. Resume checks the file size and samples its beginning and end; this is not verification of every byte of the source file.

Ready for your source archive.

PHONE & GOOGLE DRIVE → PRIVATE SOURCE

Give the citadel a durable source.

Select a file from your phone or choose Google Drive in Android’s file picker, if available. Uploads use resumable, verified chunks. Source files go to private Cloudflare storage, never GitHub.

Checking private storage…

Drive access and recovery

Tap the file selector, then open the picker’s location menu and choose Drive. This uses Android’s file provider, not a direct Google account connection. Drive may download the selected file to your phone before returning it.

This preview uses an operator access code to create uploads. A private upload credential is then stored in this browser. Do not share it. Losing browser site data loses this credential; account-based recovery is not implemented. Keep the original source.

Maximum source size: 5 GiB. Files must be unzipped JSON for the conversation indexer. Pause and resume work between 8 MiB chunks. Switching apps requests a pause.

Choose a source when you are ready.
