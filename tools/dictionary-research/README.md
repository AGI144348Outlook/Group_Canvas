# Private dictionary recovery

Pre-test plan and after-report: https://github.com/AGI144348Outlook/Group_Canvas/issues/3 .

Codex-defined search of completed GPT exports and pinned Claude conversations in existing private R2 sources. Uses actual preserved Genesis indexing/similarity for retained excerpts, without granting definitions authoritative status. No inference/training/deployment. Source files unchanged; derived JSON/Markdown/provenance saved to private cabinet collection **Dictionary recovery · Echo**, with SHA-256 readback.

The Actions workflow tests synthetic parsing fixtures, scans with existing server-held credentials, returns public aggregate metrics and an owner-encrypted compressed report. Only the public encryption certificate is committed. Full source passages and the private decryption key are never committed or logged. At most 5,000 candidate messages and 20 MiB serialized output; counts of omitted/partial records remain explicit. See script docstrings and issue for scope/limits. Actual source searches require the repository pre-test protocol.
