# Conversation Line

Android-first, isolated Group Canvas artifact for arranging GPT source blocks evenly along an extendable UTC month line. Block positions are editorial spacing; conversation timestamps determine the separate monthly counts. Selecting a block and month filters the displayed counts, without loading transcripts.

The anonymous view uses explicitly fictional data. Enter the existing file-cabinet operator code to open the private compact manifest. The code is used for a single request and not persisted. Only revision-scoped view/review preferences persist locally. Closing the private view clears its metadata from the interface. Private file IDs and source labels are not published as static assets.

## Reproduction

Run `node --test tests.mjs worker.test.mjs`. The workflow prepares a private manifest from the existing checksum-verified chronology and current cabinet inventory, read-back verifies its derived R2 upload, deploys this isolated Worker, and runs phone-sized browser checks. `prepare.mjs` requires the existing `CREATE_ROOM_KEY`; it does not read original source exports, call external models, or modify tower production code. Missing chronology coverage remains unknown; pending uploads are never counted as empty sources.

`python browser_test.py` checks the hosted artifact with Chromium and a 390 × 844 touch viewport. The optional environment credential also checks the real private manifest, without logging source identifiers or taking private screenshots. Public QA artifacts contain only fictional screenshots and aggregate pass results.

## Boundaries

Timothy's order is vocabulary/context assessment → existing placement → consideration of a new Matrix folder last. This artifact implements source layout and month selection only. It does not qualify vocabulary, color unknown/known words, create Matrix folders, admit definitions, infer character identity, train adapters, or assert comprehension. Its manual progress marker is not an automated test result.

All recorded GPT branches remain in the saved chronology counts. A record referenced by more than one source can contribute to multiple per-block counts; global record counts must not be reconstructed by summing overlapping blocks. Calendar months have equal display widths, despite different numbers of days. New upload contents require a subsequent chronology refresh before their dates can be shown.
