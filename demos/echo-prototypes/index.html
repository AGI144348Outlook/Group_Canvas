03 / Inspect the machinery
Mapped algorithm combinations
These records point to code; clicking a record does not run it. “Specified” and “proposed” entries are not executable abilities.
What happened with the dictionary?
In the recorded experiment, 1,000 dictionary words produced 1,491 sense cards and 2,713 ties. Making blocks available caused no spontaneous actions. Explicitly started routines accepted 40 statement candidates, including “An time place”. Those outputs exposed weak validation; they were not accepted as proven logic.
There is no autonomous dispatcher, general comprehension engine, image recognition, training, or §DSL§ inversion running here.
The developmental path
Identification → structure → comprehension → generalization → inference → composition → Recursive Return → transfer.
Each stage needs separate lessons, unseen tests, retention checks and counterexamples. This demo does not award mastery badges.


04 / Echo as an indexing assistant
A line long enough for the whole archive.
Pan with one finger; pinch or use the zoom buttons to move from years to individual records. This starts with fictional sample records. Load your private generated index to inspect actual conversations locally.
Files stay in this page’s memory. No uploads or model calls. The index contains private titles and source pointers, not full transcripts.
Undated records and ordering limits
Missing timestamps remain unresolved; they are not silently placed at the conversation’s start. Alternate OpenAI branches are retained. Dates mentioned inside messages are candidates, not accepted historical events.
Read, test, inspect.
Browser mode is a JavaScript counterpart tested against Python-generated fixtures. Original Python mode runs the embedded repository modules in Pyodide, with an isolated in-memory catalog. Its first load needs internet. Saving uses this browser’s storage when available; exported JSON is the portable record.
